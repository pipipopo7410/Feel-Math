數感小島｜0～100 擴充版（PWA）
=================================

這是可在 iPad Safari 加入主畫面、離線運作的單頁網頁 App。
使用系統字型，不依賴線上圖片／函式庫；首次連線部署與啟動後可測試斷網操作。

操作任務（九種）：
  數一數：0～100；0 表示沒有物件，21 以上顯示十個一組的積木
  比一比：0～100；比較更多、更少、相等
  分一分：0～10 可觸控拖曳；較大數量改用十位、個位分組
  補一補：0～10 使用十格框；11～100 使用 +10/+1 操作，以免十格框不足
  數線走走：0～100；+/-1、+/-10 的數線跳躍
  十的魔法：0～100；建構十位個位和 10 個一與一個十的交換
  跨十小橋：0～100 範圍內、跨十加減問題，採二步法
  靈活計算：0～100；自選 +10/+1/-10/-1 解題
  自由積木：0～100 無答錯壓力，可自由調整、交換

三種可直接選擇的數量範圍：0～10、0～20、0～100；高階「十的魔法」「跨十小橋」最低使用 0～20。
「推薦」根據活動紀錄提供初步引導，但不會鎖定或阻擋跳關。
學習歷程以操作證據累積，不宣稱能準確判讀孩子的心理策略。

部署更新原本 GitHub Pages 專案：
1. 解壓本 ZIP，將裡面所有檔案上傳到原本儲存庫的根目錄，覆寫同名檔案。
2. GitHub Pages 若仍部署該儲存庫 main/root，無須另外建立新網址。
3. 開 iPad Safari 進入原網址、連網重新整理，必要時關閉／重開主畫面 App。
4. 確認新版首頁有「0～100」和九種遊戲後，關掉 Wi-Fi 重新測試離線。
5. 別刪除原 App 或清除網站資料，以免失去原本學習紀錄；更換網址來源也可能使紀錄無法共用。

家長頁：本機 IndexedDB 儲存／保留前版紀錄（同源更新時）；匯出／匯入 JSON。
提醒：iOS 版本、Safari 儲存政策與裝置空間管理可能影響離線儲存和持久性，務必實機測試並定期備份。

這是教育設計原型，不是教育測驗；難度演算法與能力狀態尚未通過教學現場效度驗證。
