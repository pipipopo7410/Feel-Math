數感小島 2.4（0～100）｜操作與語音升級版

1. 六種主題圖案：🐰 🚗 ✈️ 🐱 🍎 🍬。點首頁或頁首的「↻」按鈕即可輪流切換，所有活動共享同一圖案。
2. 十進位：放滿十格盒後整盒放旁邊；操作時顯示 10+10=20、20+3=23 等關係。0～100 模式首次進入「十的魔法」以 23 作示範。
3. 金幣：每完成一道題目 +1，保存在本機 localStorage。可由家長和孩子自行約定兌換規則；本 App 不提供實際兌換或購買功能。
4. 語音：使用裝置的語音合成（zh-TW），按「🗣️ ▶」可重聽題目。頁首 🗣️／🤫 可切換語音；🎵／🔕 切換音效。iPad 離線時中文語音能否播放，取決於本機是否具備相應的語音包；圖像和遊戲不受影響。
5. 數線：固定數線範圍、每格 1，不顯示標靶；從起點到目前位置畫箭頭並顯示累計 +3 / -2 等，保留拖曳和 -1 / +1。
6. 九種活動維持；家長觀察紀錄功能留在首頁右下角 ⚙️，不是本版的設計重點。
7. 仍保留 IndexedDB 舊紀錄及 JSON 匯出／匯入功能；升級前建議先從舊版本匯出備份。

更新 GitHub Pages：解壓後，把全部 6 個檔案上傳覆寫到既有 repository 的根目錄，保持 Pages branch main / (root)。不要只上傳 ZIP。iPad Safari 連網重新載入一次，必要時關閉再開啟主畫面 App，確認版本與離線功能。

此版本的中文語音以 iPad 系統提供的聲音為準，並非內建真人錄音；離線語音可能受 iPad 設定限制。可完全關閉語音。
